# FilmCut 裁片

胶片 / 拍立得 / 宝丽来 **扫描件裁剪**专用工具。与 [ImgMark](https://github.com/techysy/imgmark) 同架构：Node + Express + sharp 的本机 HTTP 服务 + 浏览器 UI + CLI，无鉴权、默认只绑 `127.0.0.1`。

## 它解决什么

扫描仪出来的图是「白纸 + 相纸」：相纸歪斜、周围有手写字、一次扫好几张。FilmCut 做 four 件事：

1. **自动检测**：白底上的相纸区域（连通域 + 最小面积外接矩形），一纸多张分别检出
2. **自动摆正**：最小外接矩形给出倾斜角，裁剪时反向旋转
3. **固定分辨率**：按相纸方案设定的输出长边等比输出（同一种相纸出的图尺寸永远一致）
4. **方案固定**：相纸方案（比例 / 输出长边 / 白底容差 / 外扩）持久化在数据目录，扫描哪种相纸就用哪个方案

手写在相纸边框上的字会**保留**在裁剪结果里（框即相纸边界）。检测自带「比例亲和」：与方案比例差 ±45% 以上的区域（相纸旁的字条、阴影）自动淘汰；界面里也可手动拖框（按方案比例锁定）、微调旋转角，或**沿相纸边拉一条参考线**来摆正——检测角被手写字带歪时，这条线比自动检测更可靠。

## 内置方案

Instax Mini / Square / Wide（整张相纸与画面区两种比例）、Polaroid 600、135 胶片单帧（横/竖），均可编辑或另存自定义方案。

## 用法

```bash
# Web 界面（默认 http://127.0.0.1:28210）
npm install && npm start
# PORT=28220 npm start 换端口

# CLI
node bin/filmcut presets                     # 列出方案
node bin/filmcut cut C:\scans -o C:\scans\cut \
     --preset "Instax Mini · 整张相纸" --skip-done
node bin/filmcut cut scan.png --out-long 1600   # 单文件，不选方案用默认参数
```

UI：选扫描目录 → 点文件载入画布 → 自动检测出框（可拖动/旋转/手动拖新框）→ 裁剪预览 → 保存；或直接「开始批量裁剪」整目录。

## 数据目录

方案存 `data/presets.json`（`FILMCUT_DATA_DIR` 可覆盖）。首次启动播种内置方案，之后编辑/新增/删除都落盘。

## 测试

```bash
npm test   # 冒烟：合成扫描件检测/摆正/固定分辨率 + 方案存储 + HTTP 全链路
```
